Add a live channel

Paste the UDP address of the TV stream. Everything else is set up automatically: Urdu speech, the Urdu-tagged audio track (or the first one), a name and an ID. The channel starts within about 10 seconds.

Advanced options (optional)

Other link types also work: (e.g. srt://host:9000?mode=caller, https://host/live/index.m3u8). Changes need the API token (🔑) when the server has one.
