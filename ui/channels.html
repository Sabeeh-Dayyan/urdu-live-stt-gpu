Supported: . Examples: multicast udp://@239.10.10.5:5000, unicast udp://0.0.0.0:5001, SRT srt://host:9000?mode=caller, HLS https://host/live/index.m3u8, RTMP rtmp://host/app/stream. The supervisor starts, restarts or stops the channel's worker within about 10 seconds of a change. Changes need the API token (🔑) when the server has one.
